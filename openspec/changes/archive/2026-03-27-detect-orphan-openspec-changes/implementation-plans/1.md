> **Task:** `1` from `detect-orphan-openspec-changes`
> **Execution mode:** Inline execution in the feature worktree using test-first changes.

**Goal:** Add shared helper logic that enumerates active unarchived OpenSpec change IDs and compares them against the change IDs linked from promoted feature files, while excluding archived directories and preserving the current completed-feature rules.

## Plan

### 1. Add a helper seam for active-vs-linked change enumeration

- Introduce a shared helper that:
  - lists active change IDs from `openspec/changes/`
  - excludes `archive/`
  - compares that active set with promoted-feature linked change IDs from the active version backlog
- Keep the output structured enough for later audit/diagnose integration.

### 2. Prove archive and completed-feature behavior with narrow tests

- Add unit coverage for:
  - an orphan active change that is not linked from any promoted feature
  - an archived change that must not be treated as active drift
  - a completed feature that still points to an archived change and must remain valid input

### 3. Verify the helper layer narrowly

- Run only the new or directly related `skills/_workflow/tests/test_workflow_state.py` tests first.
- Broaden only if the helper touches a wider shared contract than expected.

## Notes

- Keep task `1` focused on enumeration and comparison. Do not fully wire CLI findings into `diagnose-workflow` or `audit-workflow` yet; that belongs to task `2`.
