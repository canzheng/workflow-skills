- Add a small OpenSpec-backed repo fixture with an invalid `Current Task` value such as `1.1`.
- Add one failing audit test asserting the script rejects the feature with a clear message.

- Wrap the same path in `diagnose-workflow` so the diagnosis payload includes an explicit error finding and still returns a usable JSON report.

- Re-run the script-level test target after the reporting changes land.
- Re-run `python "${CODEX_HOME:-$HOME/.codex}/skills/audit-workflow/scripts/audit_workflow.py"` in the active feature worktree after the task-start state update.
