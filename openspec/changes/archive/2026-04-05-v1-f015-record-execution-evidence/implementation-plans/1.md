# Task 1 Implementation Plan

## Objective

Make task execution record validation evidence as proof is produced, so `complete-task` can remain a reconciliation gate over an already-built evidence ledger.

## Contract Surface

- Execution-time task workflow guidance in `skills/start-task/SKILL.md`
- Completion-time evidence ownership wording in `skills/complete-task/SKILL.md`
- Shared workflow reference and feature template wording for the validation log
- Shared feature-file helper behavior for appending `Run`, `Result`, and `Evidence` entries under `## 1. Validation Log`
- Workflow resolver instruction text that tells executors to record evidence during execution

## Proof Obligations

- Execution guidance must clearly assign evidence capture to task execution rather than to `complete-task`
- The shared helper must append validation entries without breaking the feature-file structure or handoff notes
- Recorded evidence must remain consumable by the existing completion-time reconciliation logic
- Focused tests must prove the helper writes the expected task-scoped validation log structure
