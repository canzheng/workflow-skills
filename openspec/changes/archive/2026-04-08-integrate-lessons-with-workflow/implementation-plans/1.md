# Task 1: Update workflow docs to integrate the lesson lifecycle

## Contract Surface

- `skills/start-task/SKILL.md` retrieves relevant active lessons after reading the linked change context and records the returned lesson IDs in the feature file handoff state.
- `skills/complete-task/SKILL.md` records lesson usage for the retrieved lesson IDs before capturing new lesson candidates, and preserves the handoff record in the feature file.
- `skills/finish-feature/SKILL.md` promotes durable lessons after the linked OpenSpec change is validated and archived, before branch finalization.
- `docs/planning/WORKFLOW_REFERENCE.md` names the lesson lifecycle canonically so the workflow no longer relies on the lesson skills alone for ordering.
- The feature file handoff notes preserve retrieved lesson IDs until `complete-task` reconciles them.
- `refresh-lessons` remains explicitly user-triggered.

## Proof Obligations

- The workflow must make lesson retrieval, usage reconciliation, candidate capture, and promotion appear at the correct task and feature lifecycle points.
- The workflow must preserve retrieved lesson IDs in the feature file until task completion can reconcile usage.
- The workflow must keep `refresh-lessons` outside the automated task lifecycle.
- The implementation must not change lesson schemas or other unrelated workflow state rules.
