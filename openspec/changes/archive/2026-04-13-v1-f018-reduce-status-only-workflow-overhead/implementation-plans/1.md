## Proof Obligations

- The workflow reference must describe the deterministic continuation payload and structured review-verdict lines as canonical workflow contract, not just feature-local shaping notes.
- The feature template must show the canonical review-verdict fields and continuation-oriented handoff shape without adding a second execution ledger.
- The stable task handoff spec must define the continuation payload fields and how autonomous execution uses them to continue without status-only relay turns.
- The stable feature-execution spec must define where structured review verdicts live in feature files and which boundaries emit terminal versus non-terminal verdicts.
- The stable audit-and-repair spec must clarify that execution-scoped helpers may continue a selected feature while surfacing unrelated malformed active work as diagnostics, without weakening the direct audit gate.
