# Task 2 Implementation Plan

## Objective

Implement the workflow-helper and resolver changes that make selected-feature continuation deterministic: `complete-task` must emit the canonical continuation payload, review verdict state must be readable through shared helpers, and selected-feature execution must stop blocking on unrelated malformed active work.

## Proof Obligations

- The shared completion handoff must expose the canonical fields `action`, `target_feature_id`, `target_task_id`, `reason`, and `requires_human_decision`, with `start_task`, `finish_feature`, and `stop` behavior matching the accepted contract.
- Resolver payloads must preserve selected-feature worktree continuation and must not block a valid selected feature because unrelated active features are malformed, while still leaving direct audit behavior unchanged.
- `finish-feature` must scope explicit `--feature-id` resolution to the named feature instead of failing on unrelated sibling `[IN_PROGRESS]` features.
- Shared workflow helpers must be able to read the structured review-verdict lines from feature-file handoff notes so later task and loop steps can consume deterministic verdict state.
- Updated tests must fail first under the old handoff shape and then pass only when the new continuation and selected-feature scoping behavior is implemented.
