## Proof Obligations

- The nine entry scripts import `WorkflowError`, `repo_root`, and (where applicable) `load_backlog` from `_workflow.cli_helpers` instead of redefining them.
- `init_workflow_artifacts.py` keeps its init-specific graceful-cwd-fallback behavior by calling the shared `repo_root(..., fallback_to_cwd=True)`; no other script uses that flag.
- `resolve_start_task.py` routes worktree enumeration through the public `list_git_worktree_roots`; the private `_list_git_worktree_roots` is gone; its failure contract is the public helper's `[root.resolve()]`.
- `audit_workflow.py` imports `FEATURE_ID_RE` from `_workflow.workflow_state` and no longer declares it locally; the previously-unused `TASK_STATUS_RE` local is removed; the script-unique `BACKLOG_REF_RE` stays local.
- The `SKILLS_ROOT = Path(__file__).resolve().parents[2]` idiom is replaced with an anchor-based walking bootstrap (`for candidate in parents; if _workflow/ child exists; break`) in every migrated script and in `skills/_workflow/tests/conftest.py`; test files that need the path through `_workflow` use the exported `resolve_skills_root()` helper.
- `load_backlog` in `cli_helpers.py` returns the canonical 3-tuple `(backlog_path, backlog_text, parsed_backlog)`; the four previous `read_backlog` callers converge on it, with `autonomous-backlog-loop` retaining its script-local `FeatureRecord` construction on top of the shared core (per design decision).
- The existing test suites pass with no assertion removed, weakened, or retargeted; only additions are permitted in `tests/` and `skills/_workflow/tests/`.
- The behavior-preservation gate is enforced by explicit regression tests for `resolve_skills_root` (walk-up from a relocated script, happy path, error path) and for the `_list_git_worktree_roots` convergence (no private copy returns; public helper is imported).

## Implementation Notes

- Bootstrap idiom: `for _candidate in Path(__file__).resolve().parents: if (_candidate / "_workflow").is_dir(): sys.path.insert(0, str(_candidate)); break`. Small enough to keep inline in each script without qualifying as duplication, and robust to relocation.
- `cli_helpers.resolve_skills_root()` is the public anchor-based resolver for callers that already have `_workflow` importable (tests, helpers). Scripts still do the walk inline because they must find `skills/` before they can import `cli_helpers`.
- `cli_helpers.load_backlog()` returns the superset `(backlog_path, backlog_text, parsed_backlog)`; `start-task` and `complete-task` discard `backlog_text`; `prioritize-backlog` uses all three; `autonomous-backlog-loop` builds its `FeatureRecord` dict on top of `load_backlog`'s core.
- The `_list_git_worktree_roots` failure-contract divergence is the behavior change called out by lesson `L-002`. Retained callers rely on `if worktree_root == root: continue`, which skips the `root` the public helper always returns; so the behavior remains identical in both success and git-error cases.
