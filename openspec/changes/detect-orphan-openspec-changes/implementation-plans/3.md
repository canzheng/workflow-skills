- Create narrow test helpers that can build:
  - an orphaned active change state where an unarchived change directory is not linked from any promoted feature
  - a repaired state where the same active change is linked from a promoted feature and should no longer be flagged

- In `tests/test_diagnose_workflow.py`, assert that:

- In `tests/test_workflow_openspec_integration.py`, assert that:
  - audit fails for the orphaned fixture
  - audit passes for the repaired fixture
